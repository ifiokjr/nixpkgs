# flutter_native_splash

`flutter_native_splash` generates native splash-screen assets and platform configuration for Flutter applications.

Use it to create or remove launch splash screens for Android, iOS, web, Windows, macOS, and Linux targets from a Flutter project configuration.

## usage

```bash
nix run github:ifiokjr/nixpkgs#flutter_native_splash -- --help
```

The package installs two executables:

- `flutter-native-splash-create`
- `flutter-native-splash-remove`

## updates

This package tracks the latest `flutter_native_splash` version published to Pub.

Run the repository updater from the repo root:

```bash
./scripts/update
```
