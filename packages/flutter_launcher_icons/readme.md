# flutter_launcher_icons

`flutter_launcher_icons` generates launcher icons for Flutter applications from a single source image and project configuration.

Use it to create Android, iOS, web, Windows, macOS, and Linux launcher icons for Flutter apps.

## usage

```bash
nix run github:ifiokjr/nixpkgs#flutter_launcher_icons -- --help
```

The installed executable is `flutter_launcher_icons`.

## updates

This package tracks the latest `flutter_launcher_icons` version published to Pub.

Run the repository updater from the repo root:

```bash
./scripts/update
```
